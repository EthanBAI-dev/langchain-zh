## 0.1 你需要准备的东西

| 项目 | 要求 | 说明 |
|---|---|---|
| Python | 3.11 – 3.13 | 课程明确要求 ≥ 3.11 |
| [uv](https://docs.astral.sh/uv/) | 最新版 | 新课程统一用 uv 管理环境，比 pip + venv 快得多 |
| git | 任意版本 | 用来下载课程仓库 |
| 模型 API Key | 至少一个 | 课程默认用 OpenAI；也可以用 Anthropic、Google 等 |
| LangSmith API Key | 可选但强烈推荐 | 免费注册，用来看每一步执行的"录像" |
| Tavily API Key | 第 9、12 章需要 | 给 Agent 用的网页搜索，有免费额度 |

## 0.2 三步装好环境

**第 1 步：安装 uv**

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
# Windows PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**第 2 步：下载课程仓库并安装依赖**

```bash
# 第 1–3 章：LangChain Essentials
git clone https://github.com/langchain-ai/lca-langchainV1-essentials.git
cd lca-langchainV1-essentials/python
uv sync            # 自动创建 .venv 并安装依赖
```

其余课程同理：

```bash
git clone https://github.com/langchain-ai/lca-lc-foundations.git     # 第 4–5 章
git clone https://github.com/langchain-ai/langchain-academy.git        # 第 6–11 章
git clone https://github.com/langchain-ai/deep-agents-from-scratch.git # 第 12 章
```

> `langchain-academy` 仓库用的是 `requirements.txt`，可以用 `python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt`。

**第 3 步：配置 API Key**

```bash
cp example.env .env
```

然后编辑 `.env`：

```bash
OPENAI_API_KEY=sk-...          # 必填（或换成你用的模型厂商）
# ANTHROPIC_API_KEY=...        # 想用 Claude 就填这个

LANGSMITH_API_KEY=lsv2_...     # 可选：开启追踪
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=langchain-py-essentials
# 如果你在欧盟区：
# LANGSMITH_ENDPOINT=https://eu.api.smith.langchain.com

TAVILY_API_KEY=tvly-...        # 第 9、12 章的网页搜索
```

在 notebook 里加载：

```python
from dotenv import load_dotenv
load_dotenv()   # 读取 .env，把变量放进环境变量
```

## 0.4 （推荐）启动 Studio：可视化调试器

每个模块下都有一个 `studio/` 目录，里面有 `langgraph.json`，告诉服务器"图在哪个文件里"：

```json
{
  "dependencies": ["."],
  "graphs": { "sql_agent": "./sql_agent1.py:agent" },
  "env": ".env"
}
```

在该目录下运行：

```bash
cp ../.env .
uv run langgraph dev
```

终端会打印三个地址：

```
- 🚀 API: http://127.0.0.1:2024
- 🎨 Studio UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
- 📚 API Docs: http://127.0.0.1:2024/docs
```

用浏览器打开 Studio UI，就能看到图的结构、逐步运行、查看每一步的状态。

> ⚠️ 课程早期视频里演示的是"LangGraph Studio 桌面版"，现在已改名为 **LangSmith Studio**，并推荐用上面的 `langgraph dev` 在浏览器里打开。Studio 不支持在 Google Colab 中使用。

## 0.5 换成别的模型

课程里写的是 `model="openai:gpt-5-mini"`，格式是 `"厂商:模型名"`。换模型只需要：

```python
agent = create_agent(model="anthropic:claude-sonnet-4-5", ...)   # 需要 ANTHROPIC_API_KEY
agent = create_agent(model="google_genai:gemini-2.5-pro", ...)   # 需要 GOOGLE_API_KEY
```

或者先初始化模型对象再传入：

```python
from langchain.chat_models import init_chat_model
llm = init_chat_model("openai:gpt-5", temperature=0)
agent = create_agent(model=llm, ...)
```

> 课程原话：换成不同的模型，结果可能和 notebook 里的不一样。这很正常。
