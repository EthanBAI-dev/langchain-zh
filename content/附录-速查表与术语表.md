## A. 一页纸速查

### LangChain：create_agent

```python
from langchain.agents import create_agent
from langchain.tools import tool
from langgraph.checkpoint.memory import InMemorySaver

@tool
def my_tool(x: str) -> str:
    """一句话说明什么时候该用这个工具。"""
    return ...

agent = create_agent(
    model="openai:gpt-5-mini",          # "厂商:模型"
    tools=[my_tool],
    system_prompt="你是……",
    checkpointer=InMemorySaver(),       # 短期记忆（可选）
    response_format=MySchema,           # 结构化输出（可选）→ result["structured_response"]
    context_schema=MyContext,           # 运行时依赖（可选）→ get_runtime(MyContext).context
    middleware=[...],                   # 中间件（可选）
)

config = {"configurable": {"thread_id": "1"}}
result = agent.invoke({"messages": "问题"}, config, context=MyContext(...))
for chunk in agent.stream({"messages": "问题"}, config, stream_mode="messages"): ...
```

### LangGraph：StateGraph

```python
from typing import Annotated
from typing_extensions import TypedDict
import operator
from langgraph.graph import StateGraph, MessagesState, START, END
from langgraph.prebuilt import ToolNode, tools_condition
from langgraph.types import Send, Command, interrupt

class State(MessagesState):                       # 自带 messages + add_messages
    items: Annotated[list, operator.add]          # 并行写入需要 reducer

builder = StateGraph(State, input_schema=In, output_schema=Out)
builder.add_node("assistant", assistant_fn)
builder.add_node("tools", ToolNode(tools))
builder.add_node("sub", subgraph_builder.compile())       # 子图
builder.add_edge(START, "assistant")
builder.add_conditional_edges("assistant", tools_condition)
builder.add_edge("tools", "assistant")
builder.add_edge(["a", "b"], "c")                          # 扇入
# 条件边返回 [Send("node", {...}), ...]                    # Map-Reduce

graph = builder.compile(checkpointer=..., store=..., interrupt_before=["tools"])
```

### 人在回路 & 时间旅行

| 目的 | 代码 |
|---|---|
| 查看当前状态 / 下一步 | `graph.get_state(config)`、`.next` |
| 从断点继续 | `graph.stream(None, config)` |
| 节点内动态暂停 | `answer = interrupt(payload)` |
| 回应暂停 | `graph.stream(Command(resume=值), config)` |
| 修改状态 | `graph.update_state(config, {...}, as_node="xxx")` |
| 浏览历史 | `list(graph.get_state_history(config))` |
| 回放 | `graph.stream(None, old_state.config)` |
| 分叉 | `cfg = graph.update_state(old_state.config, {...})` → `graph.stream(None, cfg)` |

### 消息 reducer：add_messages

| 返回什么 | 效果 |
|---|---|
| 新消息（新 id 或无 id） | 追加 |
| 与已有消息相同 id 的消息 | 覆盖 |
| `RemoveMessage(id=...)` | 删除 |

### 流式模式

| `stream_mode` | 内容 |
|---|---|
| `values` | 每步之后的完整状态 |
| `updates` | 每步的增量 `{节点: 更新}` |
| `messages` | 模型逐 token |
| `custom` | 工具里 `get_stream_writer()` 推送的内容 |

### 记忆

| | 短期 | 长期 |
|---|---|---|
| 组件 | checkpointer（`InMemorySaver` / `SqliteSaver` / `PostgresSaver`） | store（`InMemoryStore` / `PostgresStore`） |
| 标识 | `thread_id` | `namespace` 元组（常含 `user_id`）+ `key` |
| 节点里拿 | 自动（就是 state） | 函数参数写 `store: BaseStore` |

### 中间件钩子

`before_agent` → `before_model` → `wrap_model_call`（包裹模型）→ `after_model` → `wrap_tool_call`（包裹工具）→ … → `after_agent`

常用内置：`HumanInTheLoopMiddleware`、`SummarizationMiddleware`、`TodoListMiddleware`、`ModelRetryMiddleware`、`ToolRetryMiddleware`、`ModelCallLimitMiddleware`、`ToolCallLimitMiddleware`、`PIIMiddleware`；装饰器：`@dynamic_prompt`、`@before_model`、`@after_model`、`@wrap_model_call`、`@wrap_tool_call`。

```python
# 第 13–14 章常用的几块
from deepagents import FilesystemPermission, AsyncSubAgent
from deepagents.backends import CompositeBackend, FilesystemBackend, StateBackend, StoreBackend
from langchain_quickjs import CodeInterpreterMiddleware
from langchain.agents.middleware import TodoListMiddleware

agent = create_deep_agent(
    model=model,
    backend=CompositeBackend(default=StateBackend(), routes={
        "/reference/": FilesystemBackend(root_dir="./reference", virtual_mode=True),
        "/memories/": StoreBackend(namespace=lambda rt: ("memory", rt.context["user_id"])),
    }),
    permissions=[FilesystemPermission(operations=["write"], paths=["/reference/**"], mode="deny")],
    skills=["/skills"],                      # 渐进式披露的操作手册
    memory=["/memories/AGENTS.md"],          # 每次运行注入 <agent_memory>

    middleware=[TodoListMiddleware(), CodeInterpreterMiddleware(ptc=["query_db"])],
    subagents=[AsyncSubAgent(name="analyst", description="...", graph_id="agent", url="http://127.0.0.1:2025")],
)
```

## B. 术语表（中英对照）

| 中文 | 英文 | 解释 | 首次出现 |
|---|---|---|---|
| 智能体 | Agent | 模型 + 工具 + 提示词，在循环中自主决策 | 第 1 章 |
| ReAct | Reason + Act | 思考 → 行动 → 观察 的循环 | 第 1 章 |
| 工具调用 | Tool calling | 模型输出"要调用哪个工具、传什么参数" | 第 1 章 |
| 运行时上下文 | Runtime context | 调用时注入的依赖（如数据库连接） | 第 1 章 |
| 消息 | Message | System / Human / AI / Tool 四类 | 第 2 章 |
| 流式 | Streaming | 结果未完成前先推送部分内容 | 第 2 章 |
| 模型上下文协议 | MCP | 连接外部工具的开放协议 | 第 2 章 |
| 检查点保存器 | Checkpointer | 每一步保存一次图的状态快照 | 第 3 章 |
| 线程 | Thread | 一段对话，用 `thread_id` 标识 | 第 3 章 |
| 结构化输出 | Structured output | 按 Schema 返回数据 | 第 3 章 |
| 中间件 | Middleware | 在 Agent 循环关键位置插入的钩子 | 第 3 章 |
| 人在回路 | Human-in-the-loop (HITL) | 让人参与审批、编辑、反馈 | 第 3、6 章 |
| 状态 | State | 图中共享的数据结构 | 第 4 章 |
| 节点 | Node | 图中做事的函数 | 第 4 章 |
| 边 / 条件边 | Edge / Conditional edge | 决定下一步去哪 | 第 4 章 |
| 归约器 | Reducer | 同一字段多次更新时的合并规则 | 第 5 章 |
| 断点 | Breakpoint | 在指定节点前/后暂停 | 第 6 章 |
| 中断 | Interrupt | 节点内动态暂停 | 第 6 章 |
| 时间旅行 | Time travel | 浏览历史、回放、分叉 | 第 6 章 |
| 超步 | Super-step | 同时执行的一批节点 | 第 7 章 |
| 扇出 / 扇入 | Fan-out / Fan-in | 一分多 / 多合一 | 第 7 章 |
| 子图 | Subgraph | 作为节点嵌入父图的图 | 第 7 章 |
| Map-Reduce | Map-Reduce | 拆分并行处理再汇总 | 第 7 章 |
| 长期记忆存储 | Store | 跨线程的键值存储 | 第 8 章 |
| 命名空间 | Namespace | Store 中的"文件夹路径" | 第 8 章 |
| 用户画像 / 记忆集合 | Profile / Collection | 两种结构化记忆形式 | 第 8 章 |
| 助手 | Assistant | 图 + 一组配置 | 第 9 章 |
| 运行 | Run | 一次图的执行 | 第 9 章 |
| 连发消息 | Double-texting | 上一轮未完成时用户又发消息 | 第 9 章 |
| 上下文工程 | Context engineering | 管理模型上下文窗口里放什么 | 第 10 章 |
| 上下文卸载 | Context offloading | 把大内容写进文件，上下文只留引用 | 第 10 章 |
| 上下文隔离 | Context isolation | 子任务交给独立上下文的子智能体 | 第 10 章 |
| 后端 | Backend | 决定文件存在哪、命令在哪执行 | 第 13 章 |
| 沙箱 | Sandbox | 和宿主机隔离的执行环境 | 第 13 章 |

| 动态子智能体 | Dynamic subagents | 由解释器里的代码循环派发子智能体 | 第 14 章 |
| 异步子智能体 | Async subagent | 跑在另一个部署上、后台执行的子智能体 | 第 14 章 |
| 追踪 | Tracing | 记录每次运行的完整过程 | 第 11 章 |
| 评估器 | Evaluator | 给输出打分的函数或模型 | 第 11 章 |

## C. 新旧 API 对照（看老教程时用）

课程视频录制于不同时间，部分 API 已更新。课程 notebook 已同步到新写法，看视频时注意：

| 旧写法 | 新写法（LangChain / LangGraph 1.x） |
|---|---|
| `from langgraph.prebuilt import create_react_agent` | `from langchain.agents import create_agent` |
| `create_react_agent(model, tools, prompt=...)` | `create_agent(model, tools, system_prompt=...)` |
| `pre_model_hook` / `post_model_hook` | 中间件 `before_model` / `after_model` |
| `from langgraph.prebuilt.chat_agent_executor import AgentState` | `from langchain.agents import AgentState` |
| `raise NodeInterrupt(...)` | `interrupt(...)` + `Command(resume=...)` |
| `StateGraph(..., input=..., output=...)` | `StateGraph(..., input_schema=..., output_schema=...)` |
| `TavilySearchResults`（langchain_community） | `TavilySearch`（langchain_tavily） |
| LangGraph Studio 桌面版 | LangSmith Studio（`langgraph dev` 后在浏览器打开） |
| LangGraph Platform / LangGraph Cloud | LangSmith Deployment |
